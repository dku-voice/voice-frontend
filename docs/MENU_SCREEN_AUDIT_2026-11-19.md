## 수정 사항

- `src/App.jsx`: API 응답 전/실패 시 나타나던 임시 메뉴 19개를 제거했습니다. 예를 들어 임시 감자튀김은 2,500원, 콜라는 2,000원이었지만 실제 응답은 각각 2,200원과 2,100원입니다. 이제 첫 조회 전에는 로딩만, 실패 시에는 오류·재시도를 표시합니다. 빈 정상 응답과 조회 실패도 구분합니다.
- 재조회 중/실패 시 마지막 메뉴 정보로 새 상품을 담지 못하게 하고, 재조회 실패 화면에는 마지막 정보임을 명시합니다. 정상 응답을 다시 받으면 담기를 허용합니다. 이미 생성된 주문 및 인증 결과는 변경하거나 삭제하지 않습니다.
- `src/domain/menu-display.js`: 예전 임시 상품 이름에 맞춘 추천 규칙을 제거하고, 현재 서버의 ACTIVE 상품 중 장바구니에 없는 상품을 목록으로 제시합니다. AI 후보도 현재 카탈로그의 이름·가격·이미지·옵션으로 다시 확인하며 품절·비활성·삭제·중복 후보를 제외합니다. 구매 확률/개인화 모델을 구현했다는 안내와 가짜 신뢰도는 표시하지 않습니다.
- `src/components/MenuImage.jsx`: 정상 이미지는 기존과 같은 img/CSS로 표시합니다. 주소가 없거나 로딩에 실패하면 빈 영역이나 다른 상품의 예시 이미지 대신 `이미지 없음`을 표시합니다. URL이 바뀌면 다시 로딩합니다.
- 연령 버튼의 무작위 숫자 생성을 제거했습니다. 기존 연령 화면과 이동 버튼은 유지하되 결과가 없으면 API 미연결·수신 대기를 안내합니다. 기존 음성 서버 이벤트로 실제 결과가 수신되면 해당 값을 표시합니다. 연령별 추천 기능이 있다는 문구도 제거했습니다.
- 사진 전송 주소가 없는 환경에서는 AI 응답 지연 안내가 스냅샷 전송을 약속하지 않도록 했습니다. KDS의 결제 화면 이동 버튼을 `현재 장바구니 결제`로 설명하고, 조회 오류를 주문 0건으로 오해하지 않도록 빈 목록 안내를 숨겼습니다.
- CSS, 화면 배치, 장바구니 수량/옵션 처리, 주문 생성·승인·콜백·복구 모듈은 변경하지 않았습니다.

1. **9개 메뉴의 동일 옵션 반복 반환**: ID 1~8은 실제 옵션 8개가 각각 56/48/64/40/40/56/40/48행으로, ID 9는 실제 소스 3개가 6행으로 반환됩니다. 프론트는 기존대로 이름·번역·종류·가격까지 완전히 같은 행만 한 번 표시하고 서로 충돌하면 응답을 거부합니다. 중복 원인(조회 조인 등)은 서버에서 확인해야 하며, 확인 없이 서버 데이터나 옵션 ID를 수정하지 않았습니다.
2. **설명 필드 누락**: 전달받은 명세의 descriptionKo/descriptionEn은 현재 17개 응답에 모두 없습니다. 설명을 추측해 채우지 않았습니다. 설명 표시가 필요하면 서버 응답 계약을 확인해야 합니다.
3. 현재 응답에는 SOLD_OUT/INACTIVE 사례가 없습니다. ACTIVE를 임의로 품절로 바꾸지 않았습니다. 해당 상태의 숨김·담기 차단은 별도 테스트용 응답으로 확인했습니다.
4. 영양·알레르기 값은 받은 정보를 표시하며 임의로 보정하지 않았습니다. 식품 정보의 실제 정확성은 서버 원본 데이터와 담당자 확인이 필요합니다.
